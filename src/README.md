# Source structure

- `components/ui` — small, reusable presentation components such as buttons, inputs, and modals.
- `components/common` — shared composed components, such as page headers and empty states.
- `containers` — feature-level components that coordinate data and UI components.
- `hooks` — reusable React hooks.
- `features` — Redux feature slices and feature-specific state.
- `store` — Redux store configuration, typed hooks, and root state exports.
- `services` — API clients and external-service integrations.
- `types` — shared TypeScript types.
- `utils` — framework-independent helper functions.
