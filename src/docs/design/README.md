# Repository structure

SwissRe case-study dashboard built with React, Vite, Material UI, and Redux Toolkit. This document describes every folder in the project and its purpose.

## Root-level folders

| Folder          | Purpose                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `public/`       | Static assets served as-is by Vite. Holds mock API data (`customers.json`), the favicon, and shared SVG icons referenced by the UI. |
| `src/`          | Application source code — components, state, services, and documentation.                                                           |
| `dist/`         | Production build output generated by `npm run build`. Not edited by hand.                                                           |
| `node_modules/` | Installed npm dependencies. Generated by `npm install`.                                                                             |

## Root-level config files

| File                 | Purpose                                                                              |
| -------------------- | ------------------------------------------------------------------------------------ |
| `index.html`         | Vite entry HTML; mounts the React app into `#root`.                                  |
| `package.json`       | Project metadata, npm scripts (`dev`, `build`, `lint`, `preview`), and dependencies. |
| `vite.config.ts`     | Vite bundler configuration (React plugin, dev server, build options).                |
| `tsconfig.json`      | Base TypeScript project references.                                                  |
| `tsconfig.app.json`  | TypeScript config for application code under `src/`.                                 |
| `tsconfig.node.json` | TypeScript config for Node-side tooling (e.g. Vite config).                          |
| `eslint.config.js`   | ESLint flat config for TypeScript and React lint rules.                              |
| `.gitignore`         | Files and directories excluded from version control.                                 |
| `README.md`          | Top-level project overview and development setup instructions.                       |

## `src/` — application source

### Entry and shell

| Path        | Purpose                                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------------------- |
| `main.tsx`  | React bootstrap: renders the app inside `StrictMode`, wraps it with an error boundary and global providers. |
| `App.tsx`   | Root application component; currently renders the dashboard container.                                      |
| `App.css`   | Component-scoped styles for `App`.                                                                          |
| `index.css` | Global CSS reset and base styles applied across the app.                                                    |

### `src/components/`

| Path                 | Purpose                                                                                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `components/ui/`     | Placeholder for small, reusable presentation primitives (buttons, inputs, modals). Currently empty; reserved for custom UI building blocks that wrap or extend MUI. |
| `components/common/` | Shared, composed UI used across features: sidebar navigation, metric cards, customer table, role selector, permission gate, toast provider, and error fallback.     |

### `src/containers/`

Feature-level page components that wire together Redux state, side effects, and common UI.

| File                     | Purpose                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `DashboardContainer.tsx` | Main dashboard view: loads customers, filters sidebar by RBAC permissions, renders metrics and the customer table. |

### `src/features/`

Redux feature modules — each subfolder owns slice state, async thunks, and feature-specific logic.

| Path                  | Purpose                                                                                                                                                   |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/app/`       | Global app-level state (e.g. loading flag) via `appSlice.ts`.                                                                                             |
| `features/auth/`      | Authentication and authorization: `authSlice.ts` holds the current user; `authorization.ts` defines roles, permissions, and RBAC mappings used by the UI. |
| `features/customers/` | Customer data state: `customersSlice.ts` fetches and stores the customer list with loading/error status.                                                  |

### `src/store/`

Redux store configuration and typed React-Redux hooks.

| File       | Purpose                                                                          |
| ---------- | -------------------------------------------------------------------------------- |
| `store.ts` | Combines feature reducers (`app`, `auth`, `customers`) into the root store.      |
| `hooks.ts` | Typed `useAppDispatch` and `useAppSelector` wrappers for type-safe store access. |

### `src/services/`

API clients and cross-cutting service helpers.

| File                  | Purpose                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------- |
| `axiosInstance.ts`    | Shared Axios client with base URL, auth token injection, and global error-toast handling. |
| `customer.service.ts` | Customer API: fetches the customer list from `public/customers.json`.                     |
| `toast.service.ts`    | Imperative toast notifications consumed by Axios interceptors and UI code.                |

### `src/providers/`

React context and third-party provider composition.

| File               | Purpose                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------- |
| `AppProviders.tsx` | Wraps the app with Redux `Provider`, MUI `ThemeProvider`, `CssBaseline`, and `ToastProvider`. |

### `src/hooks/`

Reusable React hooks shared across components.

| File               | Purpose                                                       |
| ------------------ | ------------------------------------------------------------- |
| `usePermission.ts` | Returns whether the current user has a given RBAC permission. |

### `src/constants/`

Application-wide constants, copy text, and shared domain types.

| File               | Purpose                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `app.constants.ts` | UI copy, sidebar configuration, dashboard metrics, customer table labels, `Customer` type, API config, and storage keys. |

### `src/theme/`

Material UI theming.

| File          | Purpose                                                                             |
| ------------- | ----------------------------------------------------------------------------------- |
| `appTheme.ts` | MUI theme definition: palette, typography (Poppins), shape, and component defaults. |

### Reserved / placeholder folders

These folders exist to keep the architecture scalable; they are currently empty (tracked via `.gitkeep`).

| Path          | Purpose                                                                     |
| ------------- | --------------------------------------------------------------------------- |
| `src/types/`  | Shared TypeScript interfaces and type aliases not tied to a single feature. |
| `src/utils/`  | Framework-independent helper functions (formatting, validation, etc.).      |
| `src/assets/` | Bundled static assets imported by components (images, fonts, local SVGs).   |

### `src/docs/`

Project documentation living alongside the source.

| Path                    | Purpose                                                                       |
| ----------------------- | ----------------------------------------------------------------------------- |
| `docs/design/`          | Design and architecture docs for the application.                             |
| `docs/design/README.md` | This file — folder layout and responsibilities.                               |
| `docs/design/HLD.md`    | High-level design document (architecture diagrams, data flow, key decisions). |

## Data flow overview

```
public/customers.json
        │
        ▼
customer.service.ts  ──►  customersSlice (Redux)  ──►  DashboardContainer
        ▲                                                        │
axiosInstance.ts                                                 ▼
                                                        components/common/*
authSlice + authorization.ts  ──►  PermissionGate / RoleSelector / Sidebar
```

## Tech stack

- **UI:** React 19, Material UI 9, Emotion
- **State:** Redux Toolkit, React-Redux
- **HTTP:** Axios
- **Build:** Vite 8, TypeScript 6
- **Other:** react-error-boundary, react-virtuoso / react-window (virtualized lists)
